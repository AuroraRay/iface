# 护肤品存量管理系统 · 使用说明

> 面向最终用户的操作指南。内容与版本 v1.0 同步，覆盖所有已上线功能。

---

## 快速开始

1. 启动应用：在项目目录运行 `npm.cmd run dev`，浏览器打开 http://localhost:8080/
2. 首次进入即载入系统示例库存（24 件产品），直接可以体验
3. 所有数据保存在浏览器本地（localStorage），换浏览器或清理缓存会丢失，请自行备份

## 页面导航

左侧侧边栏共有四个入口：

| 图标 | 名称 | 说明 |
|------|------|------|
| 📊 | 库存概览 | 首页，数据看板 + 护理方案 + 使用计划 |
| 📦 | 库存管理 | 产品增删改查、分类筛选、使用记录 |
| 📅 | 使用日历 | 整月打卡记录，可回看、可撤销 |
| ➕ | 批量录入 | 一次录入多件产品 |

## 一、库存概览

### 1.1 顶部 KPI 卡片

| 卡片 | 含义 |
|------|------|
| 产品总数 | 库存里一共有多少件 |
| 使用中 | 正在使用（已开封且在消耗）的件数 |
| 未开封全新 | 还没开封的件数 |
| 已过期 | 超过保质期的件数（需要尽快处理） |

### 1.2 分类占比饼图

- **点击任意扇区** → 下方展开该分类的产品列表
- 列表里能看到每件产品的名称、品牌、剩余量、状态徽章
- **再次点击同一扇区** 或点右上角 ✕ 关闭
- 点击列表里的产品行会跳到"库存管理"页

### 1.3 右侧三 Tab 卡片

| Tab | 内容 |
|-----|------|
| 保质期进度 | 横向条形图，按"剩余天数从少到多"排序；🟢 安全 / 🟠 ≤90 天 / 🔴 已过期 |
| 存量概览 | 左侧：各分类有多少件；右侧：剩余量分布环形图（全新 / 储备 / 使用中 / 接近用完） |
| 使用日历 | 近 14 天迷你日历，有打卡的日子显示小圆点；点击展开当日明细 |

### 1.4 月度使用趋势

展示最近 6 个月的累计使用量（百分比），用来观察自己是不是有在持续用。

## 二、护理方案（FR-A · FR-B）

### 2.1 预设方案

系统内置 5 套方案，自动根据库存里的功效标签和分类匹配产品：

| 方案 | 目标 | 典型步骤 |
|------|------|---------|
| ✨ 美白提亮方案 | 美白/提亮/淡斑 | 洁面 → 爽肤水 → 美白精华 → 美白面霜 → 防晒 |
| 💧 补水保湿方案 | 保湿/补水/修护 | 洁面 → 保湿水 → 保湿精华 → 保湿面霜 |
| 🌙 抗老紧致方案 | 抗老/紧致/抗氧化 | 洁面 → 爽肤水 → 抗老精华 → 抗老面霜 |
| 🌿 油痘平衡方案 | 控油/祛痘/舒缓 | 洁面 → 平衡水 → 祛痘精华 → 清爽面霜 |
| ☀️ 日间防护方案 | 防晒 | 洁面 → 爽肤水 → 日间精华 → 防晒 |

每套方案卡片显示：匹配度百分比 + 进度条、步骤列表、每步关联的产品名和剩余量。

### 2.2 自定义方案（管理方案）

点击概览页"护理方案"标题旁的 **管理方案** 按钮 → 打开全屏弹层。

**左侧方案列表**：预设置顶、自定义在下；每个方案显示图标、名称、步骤数。

**新建自定义方案**：
1. 点"新建方案"
2. 填名称（必填，最多 20 字）、选 emoji 图标
3. 添加步骤：选择步骤类型（洁面/爽肤水/精华...）、可选绑定具体库存产品、设置默认用量（%，5% 步进）
4. 保存后方案卡立刻出现在概览页

**复制预设为自定义**：在预设方案卡上点"复制"，深拷贝全部步骤，名称自动为"预设名 + 副本"，之后可以自由编辑。

**编辑 / 删除**：在自定义方案卡上操作。删除只删除方案本身，产品和历史打卡记录不受影响。

### 2.3 一键打卡

每张方案卡右上角都有 **打卡** 按钮：

1. 打开确认单，每行显示：产品名、分类、默认用量（可按 ±5% 调整）
2. 取消复选框 = 本次没用这件（比如今天只做了洁面 + 防晒）
3. 底部汇总"本次将扣减 N 件产品 · 合计 M%"
4. 点 **确认打卡** → 系统一次性完成：
   - 生成 N 条产品使用记录
   - 扣减每件产品的剩余量
   - 剩余量归零自动标记"已用完"
   - 生成 1 条打卡记录（关联该方案）
5. 右下角 toast 弹出，含 **撤销** 入口

**撤销**（仅当日）：toast 里点"撤销"，或去"使用日历"页找到当日记录点撤销 → 反向恢复数量和状态。跨日不可撤销，保证日历数据稳定。

**同一方案一天可以打卡多次**（早晚各一次），每次独立生成记录。

## 三、使用日历（FR-C）

**两处入口**：

| 入口 | 位置 | 展示范围 |
|------|------|---------|
| 迷你日历 | 概览页右侧第三 Tab | 近 14 天 |
| 完整日历页 | 侧边栏"使用日历"（`/calendar`） | 整月 |

### 3.1 完整日历页

- **顶部统计条**：打卡天数 / 总天数、打卡总次数、最常用方案
- **月历网格**：周一起始，上/下月切换按钮 + "今天"快捷跳回；有打卡的日期显示小圆点（多方案最多 3 个 + 数字）
- **右侧当日明细**：方案名、打卡时间、逐产品实扣用量、合计；当日记录可撤销（需二次确认）
- 未来日期不可点击；跨月空态会提示"去概览页试试一键打卡"

### 3.2 迷你日历（概览页）

展示近 14 天，交互逻辑同完整页，只是尺寸缩小。

## 四、使用计划（FR-D）

概览页"护理方案"上方区块，用来把"这个月想美白 / 想多用某产品"变成可追踪的承诺。

### 4.1 计划卡结构

```
┌─ ✨ 2026 · 11 美白冲刺计划 ─ [进行中 / 今日计划] ─┐
│  目标：美白（微晶水 · B5精华 · 面霜）  32%          │
│  ━━━━━━━━━━━━━━━━━━━━━━━                        │
│  排程命中 3 / 8 天    本月已打卡 3 次                │
│                                                    │
│  周排程：[一] [三] [五]                             │
│                                                    │
│  今日计划 | 美白提亮方案 · 未命中今日               │
└────────────────────────────────────────────────────┘
```

### 4.2 新建计划

点 **新建计划** 按钮，填写：

| 字段 | 说明 |
|------|------|
| 月份 | 默认当前月，只能选一个 |
| 目标条目（≥1） | 三选一：① 功效方向（选功效标签如"美白"）② 指定产品（从库存挑）③ 指定方案 |
| 周排程（可选） | 选方案 + 勾选星期；可以排多条 |

### 4.3 目标进度怎么算

| 目标类型 | 进度公式 |
|---------|---------|
| 功效方向 | 本月内功效匹配产品的使用记录总量 ÷ 该组产品**计划创建时**的剩余量合计（上限 100%） |
| 指定产品 | 本月该产品使用总量 ÷ 其计划创建时剩余量 |
| 指定方案 | 本月该方案的打卡次数（无百分比，只显示次数） |

> 注意：分母按计划创建时的快照计算。计划创建后新入库的产品不计入分母——避免后来买的东西稀释进度。如果想纳入，**编辑计划时系统会重新采集快照**。

### 4.4 排程命中率

排程只作标识和统计，**不会自动打卡、不会弹提醒**。

- 命中率 = 当月"应该打卡的天数"里实际打卡的占比
- "应该打卡的天数" = 当月命中排程的星期数（比如排了周一三五，11 月有 4 个周一 + 5 个周三 + 4 个周五 = 13 天）
- 只统计排程方案的打卡记录，手动记使用不计入

### 4.5 今日计划徽标

当日命中排程时，**对应方案卡**右上角会显示"今日计划"徽标（主色高亮），打卡确认单顶部也会提示。未命中不阻断打卡。

### 4.6 编辑 / 归档

- 进行中计划：可随时编辑目标、排程；编辑会重新采集目标分母快照
- 归档：点"归档" → 二次确认 → 从主区移入"历史计划"折叠区，进度快照保留只读
- 跨月不自动归档：11 月计划到了 12 月会显示"已过期月度"角标，提醒手动归档后新建 12 月计划

## 五、库存管理

### 5.1 列表操作

- **分类筛选**：顶部分类 Tab + 关键词搜索框，快速定位
- **状态标签**：每行按保质期自动上色——🟢 正常 / 🟠 即将过期 ≤30 天 / 🔴 已过期 / ⚪ 已用完
- **记录使用**：行上点"记录使用" → 右侧抽屉打开，展示产品信息 + 使用表单 + 历史记录时间轴
- **编辑 / 删除**：行操作列按钮；删除需确认

### 5.2 状态自动计算

产品的四个状态由"开封日期 + 保质期到期日 + 剩余量"三者联动决定，无需手动设置：

| 状态 | 判定条件 |
|------|---------|
| 已用完 | 剩余量 = 0% |
| 已过期 | 保质期到期日已过 |
| 即将过期 | 保质期到期日距今 ≤ 30 天 |
| 正常 | 其余 |

## 六、数据备份与恢复

所有数据存浏览器 localStorage。键名如下：

| 键 | 内容 |
|----|------|
| `__global_skincare_products` | 库存产品列表 |
| `__global_skincare_usage_logs` | 手动使用记录 |
| `__global_skincare_custom_routines` | 自定义护理方案 |
| `__global_skincare_checkins` | 一键打卡记录 |
| `__global_skincare_plans` | 使用计划 |

**备份**：打开浏览器 DevTools → Application → Local Storage，选中对应键值复制即可。

**恢复**：同一位置手动粘贴覆盖，刷新页面。

## 七、常见问题

| 问题 | 原因 / 解决 |
|------|-------------|
| 换浏览器数据没了 | localStorage 是每个浏览器独立存储的，不跨浏览器同步；需要手动导出再导入 |
| 点"一键打卡"提示"方案内产品已用完" | 方案里所有绑定的产品剩余量都是 0%，去库存管理页补一件新的，或去方案管理里换绑产品 |
| 撤销按钮找不到 | 只有**当日**的记录能撤销；去完整日历页右侧面板，或 toast 里的撤销入口；跨日记录不可撤销 |
| 进度条百分比为什么突然变低了 | 编辑计划会重新采集目标分母快照；如果只是打卡减少了分子百分比会上升 |
| 预设方案能改吗 | 预设方案（美白/保湿/抗老/油痘/日间防护）只读；想改就点预设卡上的"复制"，生成自定义副本后随便改 |
